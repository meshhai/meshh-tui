# Triage Labels

Use a small, stable set of triage labels when GitHub Issues are enabled.

| Label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | Waiting on reporter or user clarification |
| `ready-for-agent` | Fully specified and ready for an agent to implement |
| `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | Will not be actioned |

When a skill or contributor mentions a triage role, use the corresponding label from this table instead of inventing a new synonym.
