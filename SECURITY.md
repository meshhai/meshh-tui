# Security Policy

## Supported Versions

`meshh-tui` is pre-1.0 alpha software. Security fixes target the current
`main` branch and the latest published release when one exists.

## Reporting a Vulnerability

Do not report vulnerabilities in public GitHub issues.

Use GitHub private vulnerability reporting for
`https://github.com/meshhai/meshh-tui` when available. If private reporting is
not available, open a public issue asking maintainers to enable a private
security report, but do not include exploit details, tokens, logs with secrets,
or private MESHH delivery data.

Please include:

- Affected version or commit.
- Steps to reproduce with sanitized data.
- Expected impact.
- Whether tokens, destination-scoped credentials, or delivery content may be
  exposed.

Maintainers should acknowledge valid private reports before public disclosure
and coordinate a fix or mitigation path in the private report thread.
